🔗 Sync Groups — schedule subjects simultaneously (electives, shared classes) ▼

Use Merged class to make two or more classes occupy the same time slots for a subject or split block.
Example 1 — Theory: Class 1 and Class 2 both have "Values" (3h, same teacher) → merge them → both classes get "Values" at identical slots, teacher marked busy once.
Example 2 — Split block: 1CS, 1BA, 1BCom all have "II Language" split (sans/eng/tel, same teachers) → merge them → all three classes get "II Language" at identical slots, all sub-teachers (bala, govi, ravi) marked busy simultaneously.

💡 Eligibility: Split blocks are mergeable only if all sub-option teachers are identical across classes. Theory subjects are mergeable only if the same teacher is assigned to all classes.

💡 CBSE Class 11/12 (PCM, PCB, PCMB…): Each stream is a separate class row in your data. Use Merged for shared core subjects (Physics, Chemistry, English — same teacher, same room across streams).
